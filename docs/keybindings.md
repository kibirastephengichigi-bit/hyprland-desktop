# Keybindings

Important defaults:

| Key | Action |
| --- | --- |
| `Super + Enter` | Open Kitty |
| `Super + D` | App launcher |
| `Super + W` | Wallpaper picker |
| `Ctrl + Alt + W` | Random wallpaper |
| `Super + Shift + E` | codecrafter quick settings |
| `Super + H` | Key hints |
| `Ctrl + Alt + P` | Power menu |
| `Ctrl + Alt + L` | Lock screen |

See `config/hypr/configs/Keybinds.conf` and `config/hypr/UserConfigs/UserKeybinds.conf` for the full list.
