# Customization

The main editable areas are:

- `config/hypr/UserConfigs/` for personal Hyprland overrides
- `config/hypr/UserScripts/` for user scripts
- `config/waybar/` for Waybar modules and styles
- `config/rofi/` for launchers and menus
- `assets/wallpapers/` for wallpapers copied to `~/Pictures/wallpapers`

Keep script filenames stable unless you also update keybinds and Waybar module paths.
